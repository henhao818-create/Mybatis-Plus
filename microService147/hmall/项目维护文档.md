## 3. 配置说明

### 3.1 核心配置 (`application.yaml`)
```yaml
server:
  port: 8080                    # 服务端口
  servlet:
    context-path: /api          # API 路径前缀

hm:
  jwt:
    location: classpath:hmall.jks
    alias: hmall
    password: hmall123
    tokenTTL: 30m               # Token 有效期
  auth:
    includePaths:               # 拦截器拦截路径
      - /**
    excludePaths:               # 拦截器放行路径
      - /search/**
      - /users/login
      - /items/**
      - /hi
```

### 3.2 环境配置
| 文件 | 用途 |
|------|------|
| `application-dev.yaml` | 开发环境 (服务器部署) |
| `application-local.yaml` | 本地开发环境 |

## 4. 已修复问题记录

### 4.1 购物车接口 404 错误 (2026-05-03)
**问题：** 前端请求 `/api/carts` 返回 404

**原因：** 未配置 `server.servlet.context-path`

**修复：** 在 `application.yaml` 中添加：
```yaml
server:
  servlet:
    context-path: /api
```

---

### 4.2 CORS 跨域问题 (2026-05-03)
**问题：** 前端跨域请求被浏览器阻止

**修复：** 在 `MvcConfig.java` 中添加跨域配置：
```java
@Override
public void addCorsMappings(CorsRegistry registry) {
    registry.addMapping("/**")
            .allowedOriginPatterns("*")
            .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
            .allowedHeaders("*")
            .allowCredentials(true)
            .maxAge(3600);
}
```

---

### 4.3 拦截器未生效 (2026-05-03)
**问题：** `includePaths` 未配置，导致拦截器可能不拦截任何请求

**修复：** 在 `application.yaml` 中添加：
```yaml
hm:
  auth:
    includePaths:
      - /**
```

---

### 4.4 OPTIONS 预检请求失败 (2026-05-03)
**问题：** CORS 预检请求被拦截器拦截导致 401

**修复：** 在 `LoginInterceptor.java` 中放行 OPTIONS 请求：
```java
if ("OPTIONS".equalsIgnoreCase(request.getMethod())) {
    return true;
}
```

---

### 4.5 返回值格式不一致 (2026-05-03)
**问题：** 正常响应返回裸数据，异常响应返回 `{code, msg, data}` 格式

**修复：** 创建 `CommonResponseAdvice.java` 自动包装返回值为 `R` 统一格式

---

### 4.6 参数校验缺失 (2026-05-03)
**问题：** 大部分接口缺少参数校验

**修复：**
- 为 `CartFormDTO`、`OrderFormDTO`、`OrderDetailDTO`、`ItemDTO` 添加校验注解
- 为 `PayApplyDTO`、`PayOrderFormDTO` 已有校验注解但未触发
- 在 Controller 方法参数上添加 `@Valid` 注解

---

### 4.7 路径映射不规范 (2026-05-03)
**问题：** `HelloController` 和 `PayController` 的 `@RequestMapping` 缺少前导 `/`

**修复：**
- `@RequestMapping("hi")` -> `@RequestMapping("/hi")`
- `@RequestMapping("pay-orders")` -> `@RequestMapping("/pay-orders")`

---

### 4.8 错误的注解导入 (2026-05-03)
**问题：** `CartController` 和 `OrderController` 使用了 MyBatis 的 `@Param` 注解

**修复：** 移除错误的 `@Param` 注解和 `org.apache.ibatis.annotations.Param` 导入

## 5. 常见问题排查

### 5.1 404 Not Found
**排查步骤：**
1. 确认 `server.servlet.context-path` 配置
2. 确认 Controller 的 `@RequestMapping` 路径
3. 检查请求路径是否包含 `/api` 前缀

### 5.2 401 Unauthorized
**排查步骤：**
1. 检查请求头是否包含 `authorization`
2. 检查 Token 是否过期 (有效期 30 分钟)
3. 确认请求路径是否在放行列表中

### 5.3 400 Bad Request
**排查步骤：**
1. 检查请求体 JSON 格式
2. 检查必填参数是否缺失
3. 查看响应中的 `msg` 字段获取具体错误信息

### 5.4 跨域错误
**排查步骤：**
1. 确认 `MvcConfig.java` 中的 CORS 配置
2. 检查前端请求是否携带正确的 Origin
3. 确认 OPTIONS 预检请求是否被放行

## 6. 开发指南

### 6.1 添加新接口
1. 在对应 Controller 中添加方法
2. 使用 `@Valid` + DTO 校验注解进行参数校验
3. 返回值会自动被 `CommonResponseAdvice` 包装为 `R` 格式
4. 更新本文档

### 6.2 添加新 DTO
1. 创建 DTO 类并添加 `@Data`、`@ApiModel` 注解
2. 为必填字段添加 `@NotNull`/`@NotBlank`/`@NotEmpty` 注解
3. 为数值字段添加 `@Min`/`@Max` 注解
4. 在 Controller 方法参数上添加 `@Valid` 注解

### 6.3 Swagger 文档
- 访问地址：`http://localhost:8080/api/doc.html`
- 可直接在 Swagger UI 中测试接口
